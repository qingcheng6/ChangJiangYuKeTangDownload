# 雨课堂教学资源批量导出工具（灵活网格排版）

Windows 本地工具，使用 Python、Playwright 同步 API、Tkinter/ttk。用户手动登录后，扫描“我听的课”（含账号可访问的已归档班级），勾选课堂，可选保存已发送习题图片、生成习题合集PDF、导出报告提供的静态课件页。不答题、不提交，不改变课程或课堂状态。

## 习题PDF排版

“导出设置”新增“纸张方向”和“每页排版”。默认纵向、单题一页；可选每页2/4/6/8/12张，或“自定义行列”。选择自定义后显示行数、列数，须填写正整数；非法输入在启动前友好提示，不打开浏览器。设置在开始任务时固定，执行期间禁用，不改变命名模式从下一课时生效的原有行为。每次启动默认纵向单题一页；恢复其他配置时请重新选择相同排版。

| 每页图片数 | 纵向（列×行） | 横向（列×行） |
| --- | --- | --- |
| 1 | 1×1 | 1×1 |
| 2 | 1×2 | 2×1 |
| 4 | 2×2 | 2×2 |
| 6 | 2×3 | 3×2 |
| 8 | 2×4 | 4×2 |
| 12 | 3×4 | 4×3 |

自定义完全采用输入行列，不因方向自动交换。A4四周统一10mm页边距；按原始图片顺序从左到右、从上到下填充，等比缩放、单元格内居中。题间基础间距4mm按题数平方根适配；末页仅放实际图片，已占用行和不完整行居中，不添加占位题图。排版表、页边距、间距、最低DPI和内存预算集中在`ykt/quiz_grid.py`，均有注释。

Pillow在内存中合成RGB页面，[img2pdf 0.6.3](https://pypi.org/project/img2pdf/0.6.3/)将PNG像素流无损嵌入PDF，不做JPEG有损压缩。最低300DPI，按原图细节自动提高，缩放使用LANCZOS且不下采样原图；透明通道合白底、EXIF旋转记入日志。为避免过密配置耗尽内存，单页预算4800万像素，超出会失败并提示减少行列/题数，不悄悄降清晰度。题数越多，纸面字号仍会变小，可选较少题数或在PDF中放大查看。`img2pdf`安装时会自动拉取其pikepdf等依赖；沿用已有Pillow11.3.0与pypdf6.21.4，均本地处理，不上传图片。

GUI新产物统一在原文件名末尾加排版标识，例如`第1章_习题合集_竖版1题每页.pdf`、`第1章_习题合集_带答案_竖版6题每页.pdf`。按用户确认，自定义另加行列：`第1章_习题合集_横版6题每页_2行3列.pdf`，避免与3行2列混用。日期/中文序号前缀仍在最前，课程目录、原图名称及课件PDF不变。旧PDF不迁移、不重命名；新配置独立校验和记录，不拿旧文件存在来冒充完成。旧未传排版参数的开发接口继续保留旧单图格式和旧文件名。

带答案图在内存完成原有标注后再进网格，原始下载图仍无标注；答案规则依然**仅原生正确/参考答案**，没有恢复颜色/得分反推。不同方向、行列、预设/自定义及是否带答案独立完成记录；重新运行验证页数、题数、布局、源序列、文件SHA-256和每页PNG像素流，损坏重建，失败/停止保留完整产物。“失败/未完成”按当前所选排版查看。

验收使用此前有权限下载且重新校验完整的真实14图，离线验证全部12种预设和自定义带答案模式；带答案阳性网格使用明确标记的本地样例，原生标准答案网页阳性仍未验。详见`GRID_TEST_REPORT.md`。更新代码后请重启工具，用原`run.bat`启动；不要覆盖旧`.local`与下载目录。

## 可选：标注习题答案

“导出设置”新增“标注习题答案”，每次启动默认关闭；开启会同时勾选“习题合并PDF”。关闭后仍可生成普通合集，取消习题PDF会同时取消标注。该设置在开始任务时固定，运行中不能修改；命名模式仍从下一课时生效。

按用户最终确认，**仅采用每题可见的“正确答案：A”/“参考答案：AB”等网页原生标准答案**。不读取提交选项颜色，不根据满分、个人提交答案或“全对”推断；原生字段缺失、为空、无法识别或相互冲突时，统一无可用正确答案，不标注、不猜测。此前双源自动降级已关闭，不能通过传入旧提交证据重新启用。

当前真实课时14页均未显示原生正确/参考答案，因此标注0页、原样保留14页；即使其中7题提交选项为绿色且满分，也不使用。**原生标准答案阳性DOM提取仍需真实课时补验**，目前该分支只有本地测试。现阶段识别范围为明确标签同行的选项字母，不识别图片中烧录的答案。

每题判定及原因写入日志，读取异常只影响该题；无可用答案统一为`status=missing, answer=null, confidence=none`，预留后续答案提供者入口，本版本未接入AI。按展示事件顺序、题目ID及资源摘要建立一一映射，同一原图在不同题目出现时仍分别对应答案。多图题无法可靠归属时不标注，不向图片添加“错误”“无答案”等文字。

带答案版本在`_习题合集_带答案`之后追加上述排版标识，保存在课程根目录；历史普通PDF和原图不变，三种命名模式的前缀仍置于最前。勾选原图时只保存无标注原图。仅PDF模式沿用原图临时缓存/清理机制；标注图只在内存处理，不额外落地PNG/JPEG。为避免遮住题干或选项，在原图底部增加留白，将自适应大号加粗白色字母、黑色描边和深色背景放在新增区域右下角，再整体等比放入网格；不裁剪、拉伸或修改原图文件。

两版PDF独立记录和校验页数、大小、SHA-256及来源；标注版另绑定答案映射、置信等级和策略版本3。旧策略标注记录不能被视为当前策略已完成，在“失败/未完成”提示重查；首次重新执行所选标注任务，会重建清单归属的带答案PDF，可能移除旧反推标注。升级本身不批量修改历史文件，普通PDF/原图不改动。损坏、失败或停止后可重新勾选课时执行；图片不完整时不会生成成功PDF。全部无答案时仍可生成无标记的`_带答案.pdf`，日志明确标注0页，不能据文件名认定有答案。无图片不生成空PDF。PDF-only当前策略已完成且完整时沿用原规则直接跳过，不重新抓取页面答案；若平台后来补发答案，需移走该标注PDF再运行，或使用“图片+PDF”重新检查当前DOM。历史原图不会被删除。

答案策略见`NATIVE_ONLY_TEST_REPORT.md`，当前网格验证见`GRID_TEST_REPORT.md`；`DUAL_ANSWERS_TEST_REPORT.md`及`NATIVE_ANSWERS_TEST_REPORT.md`为历史策略记录。

## V2.3 命名规则

“导出设置”中可选三种模式，首次默认“原命名”；选择会保存在本机`.local/naming_settings.json`，下次启动继续使用。旧配置没有该文件时不加任何前缀。

| 模式 | 课件PDF | 课时图片目录 | 单张图片 |
| --- | --- | --- | --- |
| 原命名 | 第1章绪论_课件.pdf | 第1章绪论 | 习题_001.jpg |
| 日期前缀 | 1016_第1章绪论_课件.pdf | 1016_第1章绪论 | 1016_习题_001.jpg |
| 课程序号 | （一）第1章绪论_课件.pdf | （一）第1章绪论 | （一）习题_001.jpg |

习题PDF使用同样前缀，`_习题合集_带答案`等后缀顺序保留，再追加方向/每页题数及自定义行列标识。

运行中切换从下一个尚未开始的课时生效；当前课时的图片与PDF继续使用其开始时的模式，无需停止或重新启动任务。一级课程文件夹不加前缀，PDF仍平铺在课程目录，图片仍放在`课程/习题图片/带前缀的课时名/`。

日期使用扫描得到的课堂授课记录时间，按北京时间转换为MMDD；缺失/无效时只对该课时回退原名并记录日志。课程序号按最近一次扫描的完整课程页默认顺序（从上到下），不按日期排序、不仅对勾选项重新计数。未勾选的有效课时保留位次；进行中课时保留页面位次。缺少有效课时/课件标识的失效记录及重复记录不占位，所选失效记录会跳过。网络/权限错误仍走原暂停或失败处理，不据此倒改已分配的历史编号。课程内容变化后请重新扫描，以使用最新页面顺序。

不同模式及其具体前缀在原任务清单中独立记录，切回已完成模式会校验后跳过，不会借用其他模式的完成标记。首次使用新模式会产生独立产物，可能重新请求资源；不重命名、移动或删除旧文件。新增课时导致序号变化时也不改旧文件；同名冲突沿原规则追加标识，前缀仍在最前。日期缺失回退原名但遇已有文件时同样保留旧文件、分配冲突名称。“失败/未完成”按当前命名模式筛选。

命名仅影响路径；账号/扫描/资源提取、PDF内容及V2.1.1课件修复保留。专项实测见`NAMING_V23_TEST_REPORT.md`。

## V2 阶段1–3：账号与可选导出

当前提供多账号管理、习题合并PDF和报告静态课件PDF。默认仅开启“下载习题图片”；三项功能可以独立组合，至少选择一项才能开始。习题与课件按课时串行处理、分别统计，课件失败不改变已有习题图片或合集。

- 首次升级将旧资料原地登记为“原有账号”，旧浏览器会话、课程缓存、保存目录和下载清单不移动、不覆盖。
- 顶部“添加…”仅创建本地账号资料项，随后打开独立浏览器，由用户手动登录平台。不同本地账号具有独立会话、缓存、导出状态和保存目录设置。平台登录失效时仍须人工重新登录。
- 选择框切换账号时先安全结束旧任务、关闭旧context，然后清除旧课程/选择/进度/日志，载入目标缓存并自动扫描。任务未退出前不能启动新账号任务。
- “管理账号…”可重命名或删除当前账号；重命名不改变ID及历史任务索引。删除需再次确认，只清理该账号会话与运行缓存，不删除已下载图片和输出目录中的历史任务清单。删除最后一个账号后可重新添加，不会重新导入已删除会话。
- “习题资源/课件资源”使用有资源、无资源、未知、检查失败四种提示。未知不代表没有资源；扫描不会为了状态逐节访问报告。资源状态随实际导出检查更新；本地状态仅反映上次检查，不证明当前权限。

V2.1桌面新任务统一直接使用您选择的保存根目录：PDF平铺在课程文件夹，图片放在`课程/习题图片/课时/`；不再自动追加“雨课堂导出文件”、账号目录或“雨课堂习题下载”。保存目录设置、账号注册表及浏览器资料不迁移。不同账号仍有独立会话、课程缓存与功能状态；输出清单按平台账号摘要隔离，同一根目录内已有的同名课程目录会分配不同名称，不会覆盖其他账号资料。也可沿用每账号各自的保存目录设置。不要在账号会话/缓存目录内选择保存路径。

CLI默认使用最后选择的账号，也可传`--account <完整本地ID>`。旧CLI参数和默认图片下载接口保留。多账号与浏览器资料占用均有本机OS锁；遇到占用提示请结束另一任务后重试，不要删除锁文件来强行打开资料。

阶段1实测为**同一平台账号的两套独立资料**：独立登录/存储、课程缓存、原生切换、停止后恢复、14张图片及无图课时通过；35项回归通过。阶段1当时未验两个不同平台账号；阶段4结果见最新 `TEST_REPORT.md`，历史范围见 `V2_STAGE1.md`。本阶段修复了平台报告frame已附着但地址尚未就绪时的过早暂停，仍保留同站点及权限检查。

### 习题合集PDF

当前GUI生成带排版标识的合集，默认A4纵向单题一页，网格能力和清晰度策略见文首。旧未传排版参数的接口仍直接生成`{课时名称}_习题合集.pdf`，JPEG可直接嵌入，其余单帧图片无损转换。两种流程均按已验证展示顺序，不从文件名字母排序猜题序；多帧图片无法确认静态展示页时明确失败，不悄悄丢弃其余帧。

| 选择 | 最终文件 |
| --- | --- |
| 仅图片 | 保存至`课程/习题图片/课时/`，原任务恢复机制不变，不生成PDF |
| 图片+习题PDF | 保留独立图片及合集；PDF失败不改变图片完成状态 |
| 仅习题PDF | 最终仅生成合集；已有历史图片保持不动，新中间图片使用独立临时缓存 |

页序来自当前报告中记录的图片展示顺序，包括重复展示引用，不使用文件名排序；图片未全部完成或页序缺失时不生成不完整PDF。无习题时跳过，不创建空PDF或空课时目录。“PDF成功课时”包含确认无图而跳过的课时，不等于生成PDF文件数。

仅PDF的工作缓存位于系统临时目录的工具专用子目录，带账号/课时归属标识和OS锁。失败、停止或进程中断时保留供续用；成功后只清理经过归属与路径校验的工作目录。可以只读复用校验通过的历史图片，但不会移动、覆盖或删除历史图片。请勿手工把下载资源放入工具临时缓存。

合集状态以可选`quiz_pdf`字段保存在原schema1任务清单，功能进度仍独立记在账号导出状态中；旧清单保持兼容。仅PDF已完成任务会校验PDF状态、大小、SHA-256、页数、A4页面和可解码图片后跳过，不重新下载中间图片。损坏/未完成PDF重新生成；文件先写独立临时文件，校验后原子替换。每次PDF生成最多重试2次；旧的完整PDF在新文件校验成功前保留，不覆盖未知归属的同名文件。

重试失败PDF时，可只勾选“习题合并PDF”，在原保存目录点击“失败 / 未完成…”选择课时，再开始处理；本地后来损坏的PDF需要重新勾选该课时以触发校验。任务总计按课时，分项计数区分图片与习题PDF；仅PDF界面中的图片写入数表示临时处理量。

阶段2实际测试和限制见 `V2_STAGE2.md`。新增单个纯Python依赖[pypdf 6.21.4](https://pypi.org/project/pypdf/6.21.4/)，用于本地写入及解析验证；没有调用云端PDF服务。图片合集直接嵌入栅格资源；课件实测方案见下方。

### 课件PDF（阶段3）

勾选“课件导出PDF”，在对应课程目录直接生成 `{课时名称}_课件.pdf`。实际课时报告是带懒加载的放映图片列表；样例原生 `page.pdf()` 只有1页，不能代表完整课件。程序逐页读取页面实际提供的授权静态图片，再复用本地PDF引擎生成A4横向、等比居中、无裁剪的合集；JPEG可直接嵌入时保留原始字节。

**导出范围是报告实际显示的静态课件页，包含其中的习题页；不承诺包含原始PPT中未放映、隐藏或未提供的页。** 课件按实际presentationId分组（组按首次出现排序），组内按原始P页码升序、稳定页ID去重；课堂静态截图（含板书/互动截图）用原报告时间标识识别，跟随当时对应页面，不使用会变化的预览临时ID。不按放映时间反复插入同一课件页。程序核对报告事件数、列表数和预览可见ID，`visible=false`且页面未显示的记录不会请求图片。页码/内容冲突、Canvas、SVG、视频或未验证的交互结构明确失败，不能可靠导出时不会生成缺页PDF；不保留动画。

课件使用独立归属的临时图片缓存，失败/停止保留供续传，成功后清理；不删除历史图片。每次重跑先核对当前报告页序及资源标识，再验证本地PDF完成状态、大小、SHA-256、页数、横向页面和图片解码，完整才跳过。资源URL不变而服务器内容被替换时，不承诺自动检测；移走PDF只触发重建，不代表强制刷新已缓存图片。图片读取和PDF生成各最多重试2次；文件先临时写入，校验成功后原子替换。

原schema1清单新增可选 `courseware_pdf` 字段，记录范围、原始页码/页ID、资源摘要、完整状态和错误。课件普通错误记入该课时后继续下一课时；登录、授权、限流继续交人工处理。损坏清单或目录权限等本地异常需先检查，不强行覆盖未知数据。只重试课件时可仅勾选课件选项，通过“失败 / 未完成…”选择原课时后执行。

## 启动

1. 安装 **64 位 CPython 3.9+**，包含 Tcl/Tk 和 Python Launcher。将项目解压到可写、较短的本地路径。
2. 双击 **`run.bat`**。首次启动会创建项目内 `.venv`、安装 `requirements.txt` 固定版本依赖，并尝试安装 Chromium，需联网。以后依赖齐全时直接启动。
3. 点击“扫描课程”，在打开的独立浏览器里使用平台原有方式手动登录；不要把密码或验证码交给程序或他人。程序根据实际课程页面确认登录。
4. 展开课程树，点击方框或按空格勾选课时。课程方框可全选/清空其子项；横线表示部分选中。选择保存目录后点击“开始下载”。
5. 点击“停止任务”安全结束；再次选择同一目录、勾选课时下载即可恢复。点击“失败 / 未完成…”查看原因，使用“仅勾选列表课时”后点击“开始下载”重试。课时已不在缓存时，先重新扫描。

默认适配 **长江雨课堂 `https://changjiang.yuketang.cn`**。内置 Chromium 优先，启动失败自动尝试已安装的 Chrome。当前验收机器内置 Chromium 有 Windows SideBySide 启动错误，实际使用 Chrome 成功；若同样遇到此问题，请使用已安装的 Chrome。界面空闲时不会自行打开浏览器。

## 会话、缓存与任务

- 浏览器会话、课程缓存、保存目录设置只保存在项目 `.local`。有效会话会尝试恢复；失效时手动重新登录。**不承诺 SessionStorage 跨启动保留**。不要分享 `.local`、浏览器资料或个人课程快照。
- “读取缓存”仅用于选择，不证明本次登录和权限有效。下载前重新验证当前账号，账号与缓存不符时暂停，重新扫描或切回原账号。
- 扫描按课程班级计数；下载按课时计数。图片保存数、完整文件跳过数、图片失败数、无图片课时数在日志另行显示。“成功课时”包含确认没有习题图片的课时。
- 新扫描会保留仍存在课时的勾选状态。同名课程班级和课时通过稳定 ID 区分；进行中的课堂显示“进行中”，报告尚不可用时记录原因，请课后重扫再试。
- 当前账号无权访问、登录失效、验证码或限流时暂停，请在浏览器人工处理并点击“人工处理完成，继续”。如果浏览器已被关闭，停止任务后重新开始。程序不绕过安全控制。

## 保存和恢复

以下为日期模式示意；原命名没有前缀，课程序号模式将相同位置的前缀替换为中文课次。

```text
所选目录/
  课程名称/
    1016_第1章绪论_课件.pdf
    1016_第1章绪论_习题合集_竖版1题每页.pdf
    1016_第1章绪论_习题合集_带答案_竖版6题每页.pdf  （可选，独立版本）
    1023_第2章进阶_课件.pdf
    1023_第2章进阶_习题合集_横版6题每页_2行3列.pdf
    习题图片/
      1016_第1章绪论/
        1016_习题_001.jpg
        1016_习题_002.jpg
      1023_第2章进阶/
        1023_习题_001.png
```

后缀来自实际解码格式，不强制 PNG。习题按页面顺序编号，同一课时重复资源或相同内容去重。课程目录仅在实际保存产物时创建；图片目录仅在保存有效图片时创建。仅PDF或整门课程无图片时不创建“习题图片”；无对应资源时不创建空PDF或空课时图片目录。

非法 Windows 字符和保留名称会替换，过长名称会截短，重名追加摘要或序号。输出路径预算为 240 个 UTF-16 单位，目录过长时会要求换短路径。不要同时用两个实例写同一输出根目录。

根目录另有工具管理的`任务清单_v21_<账号摘要>.json`和`.下载锁`文件；它们用于校验和互斥，不是资源文件夹。**请保留任务清单，不要手工修改或删除锁文件**。恢复时只有大小、SHA-256 均匹配的完整文件才跳过；丢失或损坏会重下。图片经过完整解码验证，再写 `.part`、落盘、原子重命名。每张图片首次失败后最多重试 2 次；页面超时最多重试 3 次。串行请求并限速，停止可能需等待正在进行的有超时上限的请求结束。

V2.1使用独立清单，不读取旧结构文件来充当新结构已完成结果，也不移动、修改旧图片/PDF/清单。首次在新结构执行会重新获取所选资源；以后在同一根目录重跑，只有新清单记录且校验完整的文件才跳过。未知归属同名文件保留并另分配文件名，不能只凭存在判定完成。同名/大小写或非法字符替换后重名的课程、课时会追加稳定标识摘要；图片课时目录和PDF使用同一个课时名称分配。旧开发接口仍可显式读取legacy/v2布局，桌面新任务与“失败/未完成”统一使用新布局。

清单只保存资源摘要、相对路径、完成状态和失败原因，不保存签名资源 URL 或登录凭证。损坏的清单会报错并保留，不会悄悄覆盖；请保留原文件检查，或选择其他目录。失败列表读取历史记录；若已完成图片后来损坏，仍需重新勾选该课时触发完整性检查。

## 安装排错和命令行

依赖安装失败时，检查网络、Python 版本和目录写权限。可在项目目录用 PowerShell 执行：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements.txt
.venv\Scripts\python.exe -m playwright install chromium
.venv\Scripts\python.exe main.py --gui
```

缺少 Tkinter 时修复 Python 安装并添加 Tcl/Tk。浏览器资料被占用时，关闭本工具打开的其他实例，再启动。不要在同一个浏览器资料上同时运行扫描脚本和 GUI。

```powershell
# 保留的只读扫描入口；默认手动登录并扫描，不下载图片
.venv\Scripts\python.exe main.py
.venv\Scripts\python.exe main.py --cached
# 指定已安装的浏览器
.venv\Scripts\python.exe main.py --gui --channel chrome
```

`--origin` 仅接受雨课堂 HTTPS 域名，但其他域名页面结构**尚未验证**，不能据此认为兼容。`run_stage*.bat` 和 `PHASE*.md` 是开发历史入口/记录，正常使用 `run.bat`。
